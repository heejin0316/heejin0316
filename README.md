## 🍅 About Me

SOPT 39기 Android 파트, GDGoC 7기 AI 파트 등에서 프로젝트와 스터디에 참여하며 경험을 쌓고 있습니다.

## 🐟 Projects

- **ME:WE (네이버 웨일 확장앱)**: 과목이나 과제별로 자주 사용하는 웹페이지를 **탭 모음으로 저장**하고, 필요할 때 **한 번에 다시 열 수 있는** 사이드바 확장앱입니다. 듀얼탭 구성도 함께 저장하며, **12자리 공유 코드**로 탭 모음의 독립적인 복사본을 팀원에게 전달할 수 있습니다.  
  기술: JavaScript, HTML/CSS, Manifest V3, 브라우저 확장앱 API, Firebase Firestore | [GitHub](https://github.com/heejin0316/mewe-naver-whale) · [웨일 스토어](https://store.whale.naver.com/detail/nofmokldcbhadagldehgnphoclijadka)

- **EcoTrail (안드로이드 앱)**: **GPS 주행 데이터**, **날씨·도로 상태 API**, **앱 내 계산 엔진**을 결합해 운전자가 타이어 마모 입자(TWP)의 발생과 환경 영향을 이해하고 줄일 수 있도록 돕는 React Native(Expo) 앱입니다. 결과를 담배·나무 환산 지표 등 직관적인 대시보드로 보여줍니다.  
  기술: React Native, TypeScript, Firebase, OpenWeatherMap, Overpass API | [GitHub](https://github.com/heejin0316/EcotrailApp) · [Expo 빌드](https://expo.dev/accounts/heejin0316/projects/tyre-dust-mvp/builds/1b832b74-7a1c-4613-9532-0c74e436b527)

- **ArchiveIt (크롬 확장앱)**: **2026년 10월 기준 누적 사용자 850명**을 기록한 개인정보 보호 중심 확장앱입니다. 사용자가 접근 권한을 가진 게시물을 클릭 한 번으로 정돈된 PDF로 저장합니다. **텍스트 서식과 이미지 순서**를 유지하고, 긴 이미지는 읽기 쉬운 A4 페이지로 나눕니다. 외부 서버나 추적 도구 없이 **브라우저 안에서만** 처리합니다.  
  기술: JavaScript, HTML/CSS, Chrome Extension APIs, Manifest V3, DOM API, Canvas API, Browser Print API | [GitHub](https://github.com/heejin0316/ArchiveIt) · [Chrome 웹 스토어](https://chromewebstore.google.com/detail/%EC%95%84%EC%B9%B4%EC%9D%B4%EB%B8%8C%EC%9E%87/pojgpjmfjefgnblhijhcieodeekogfah?hl=ko)

- **Pan!**: 분기형 대화, 미니게임, 멀티 엔딩을 갖춘 스토리 중심 Unity2D 게임입니다. **스토리 흐름과 장면 전환**을 구현하고, TextMeshPro와 대체 글꼴을 활용해 한국어·영어·중국어·카자흐어를 안정적으로 표시하는 **다국어 시스템**을 구축했습니다.  
  기술: Unity2D, C# | [GitHub](https://github.com/muffinhead03/OrkaGame2025_1) · [Steam](https://store.steampowered.com/app/3975970/PAN/)

- **SoundSight**: **Google Solution Challenge 2026**을 위한 React Native(Expo) 접근성 앱으로, 영상 속 소리의 감정을 실시간 시각 효과로 전달합니다. 저는 **프론트엔드와 감정-시각 효과 매핑**을 맡아, 감정 타임라인에 맞춰 화면 테두리 색과 이벤트 바가 변하는 영상 플레이어를 구현했습니다.  
  담당 기술: React Native, TypeScript, Expo | 팀 전체 기술: Firebase, Gemini API, Django, Celery, librosa, Whisper | [GitHub](https://github.com/heejin0316/2026-SolutionChallenge)

- **WhiteDay — 그림 편지 배달 (웹 앱)**: 사용자가 **캔버스에 직접 그림을 그리고** 무작위로 선택된 메시지와 함께 편지를 공유하는 서버리스 웹 앱입니다. 받는 사람은 **5단계 퀴즈**를 풀어 편지를 열고, 완성된 카드를 이미지로 저장할 수 있습니다. 공개 갤러리에서 다른 사용자의 그림도 볼 수 있습니다.  
  기술: Vanilla JavaScript, HTML5 Canvas API, Firebase Firestore, Firebase Hosting | [GitHub](https://github.com/heejin0316/WhiteDayProject) · [서비스](https://whiteday.web.app/)
